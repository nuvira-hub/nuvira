Server

The server is set by your organisation's policies (Group Policy or Intune).

Leave it empty to use the NuviraHub public server, or enter your own server (needed for shared address books and the Pro modules).

With unattended access installed this is also the server of the service: saving a new one asks for an administrator's confirmation, and the ID may change.

Terms of use of the public server

Unattended access

Install NuviraHub on this computer to reach it even when nobody is in front of it, also after a restart, with a permanent password. An administrator account is needed.

Installed: this computer can be reached even when nobody is in front of it. To remove NuviraHub use the installed apps in Windows settings.

This computer

Whoever controls this computer can turn its screen black and block its mouse and keyboard while working. Ctrl+Alt+Del always locks the computer.

During a session, what is printed on the "NuviraHub" printer of this computer comes out of the printer of whoever controls it. The printer is installed with unattended access.

Required by your organisation's rules: every session of this computer is recorded, and the strip at the top says so.

Whoever controls this computer can save a video of the session on their own computer. While it happens the strip at the top says so.

Whoever connects to this computer can open a command prompt with the rights of the user signed in, without seeing the desktop. The strip at the top says when a terminal is open.

With a NuviraHub Pro server, whoever controls this computer can reach through it the addresses of its local network, e.g. the router's web panel or another PC's Remote Desktop. Never internet addresses.

Session recordings

Sessions towards other computers are saved as MP4 videos from the start, when the person at the other computer allows it (they are told). The record button in the session bar starts and stops a recording at any time.
