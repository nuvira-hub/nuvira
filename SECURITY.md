# Security policy

NuviraHub controls computers remotely: security problems are taken seriously.

## Reporting a vulnerability

Write to **[security@nuvirahub.dev](mailto:security@nuvirahub.dev)**, not to a public issue. Please include:

- the affected component (app, server, protocol) and version;
- what an attacker can do, and under which conditions;
- the steps to reproduce it, or a proof of concept.

You will receive an answer within a few days. We will agree with you on a date for publishing the details, after a fixed version is available, and credit you in the release notes if you wish.

## Supported versions

Fixes are made on the latest release. The app updates itself from its server; servers should run the latest image.

## Scope

The app, the open server and the protocol in this repository, and the NuviraHub public server `connect.nuvirahub.dev` (do not test it with denial-of-service attacks or against other people's devices). Abuse of the public server, such as scams, goes to [abuse@nuvirahub.dev](mailto:abuse@nuvirahub.dev).
